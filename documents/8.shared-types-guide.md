# Hướng dẫn sử dụng Shared Types trong Tacohouse

## Tổng quan

Dự án Tacohouse đã được cấu hình để chia sẻ types từ Prisma cho cả Backend và Frontend thông qua package `@tacohouse/shared`.

## Cấu trúc

```
tacohouse/
├── backend/          # NestJS backend
├── frontend/         # Next.js frontend  
├── shared/           # Shared types package
│   ├── src/
│   │   └── index.ts  # Export tất cả Prisma types
│   └── node_modules/
│       └── .prisma/
│           └── client/  # Prisma generated client
└── pnpm-workspace.yaml
```

## Cách sử dụng

### 1. Trong Backend (NestJS)

```typescript
// Import types và enums
import { User, UserRole, BillStatus, Prisma } from '@tacohouse/shared';

// Sử dụng trong service
export class UserService {
  async findUser(id: string): Promise<User | null> {
    // ...
  }

  async createUser(data: Prisma.UserCreateInput): Promise<User> {
    // ...
  }
}

// Sử dụng enum
if (user.role === UserRole.LANDLORD) {
  // ...
}
```

### 2. Trong Frontend (Next.js)

```typescript
// Import types và enums
import { User, Building, Room, RoomStatus } from '@tacohouse/shared';

// Sử dụng trong components
interface Props {
  user: User;
  buildings: Building[];
}

export function Dashboard({ user, buildings }: Props) {
  return (
    <div>
      <h1>Welcome {user.email}</h1>
      {buildings.map(building => (
        <BuildingCard key={building.id} building={building} />
      ))}
    </div>
  );
}

// Sử dụng enum
if (room.status === RoomStatus.AVAILABLE) {
  // ...
}
```

### 3. API Response Types

```typescript
// Frontend - types cho API responses
import { User, Building, Room } from '@tacohouse/shared';

interface ApiResponse<T> {
  data: T;
  message: string;
  success: boolean;
}

// Sử dụng
const response: ApiResponse<User> = await fetchUser(userId);
const buildings: ApiResponse<Building[]> = await fetchBuildings();
```

## Các Types có sẵn

### Models
- `User` - Thông tin người dùng
- `UserProfile` - Profile người dùng

- `Building` - Tòa nhà
- `Room` - Phòng
- `RoomEquipment` - Thiết bị trong phòng
- `Rental` - Hợp đồng thuê

- `Payment` - Thanh toán
- `PaymentConfirmation` - Xác nhận thanh toán

- `ChatGroup`, `ChatGroupMember`, `Message` - Chat

  - `Prisma.BuildingWhereInput`
  - ... và nhiều types khác

## Workflow phát triển

### Khi thay đổi Prisma Schema

1. Sửa file `backend/prisma/schema.prisma`
2. Chạy migration:
   ```bash
   cd backend
   pnpm prisma migrate dev --name your_migration_name
   ```
3. Generate Prisma client (tự động chạy sau migrate, hoặc chạy thủ công):
   ```bash
   pnpm prisma generate
   ```
4. Build lại shared package:
   ```bash
   cd ../shared
   pnpm build

   # Go back to root
   pnpm run shared:build
   ```
5. Types mới sẽ tự động có trong cả BE và FE

### Scripts tiện ích

Từ thư mục root của project:

```bash
# Generate Prisma client
pnpm prisma:generate

# Chạy migration
pnpm prisma:migrate

# Build shared package
pnpm shared:build

# Watch mode cho shared package (tự động build khi có thay đổi)
pnpm shared:watch

# Build toàn bộ project
pnpm build

# Chạy dev cho cả BE và FE
pnpm dev
```

## Best Practices

1. **Không edit trực tiếp trong shared/node_modules/.prisma**: Đây là folder tự động generate, mọi thay đổi sẽ bị ghi đè.

2. **Luôn chạy `pnpm prisma generate` sau khi thay đổi schema**: Đảm bảo types được cập nhật.

3. **Sử dụng types đầy đủ trong API**: 
   ```typescript
   // ✅ Good
   async createBuilding(data: Prisma.BuildingCreateInput): Promise<Building>
   
   // ❌ Avoid
   async createBuilding(data: any): Promise<any>
   ```

4. **Export thêm types nếu cần**: Nếu cần thêm utility types, thêm vào `shared/src/index.ts`:
   ```typescript
   // Ví dụ: Export type cho User không có password
   export type UserWithoutPassword = Omit<User, 'password'>;
   ```

## Troubleshooting

### Types không được cập nhật
```bash
cd backend
pnpm prisma generate
cd ../shared
pnpm build
```

### Lỗi "Cannot find module '@tacohouse/shared'"
```bash
# Từ root
pnpm install
```

### IntelliSense không hoạt động
- Restart TypeScript server trong VS Code: `Cmd+Shift+P` → "TypeScript: Restart TS Server"
- Hoặc reload VS Code window

## Lợi ích

✅ **Type Safety**: Frontend và Backend sử dụng cùng types, tránh mismatch  
✅ **Single Source of Truth**: Schema trong Prisma là nguồn duy nhất cho data models  
✅ **Auto-completion**: IntelliSense hoạt động tốt với tất cả types  
✅ **Refactoring dễ dàng**: Thay đổi schema → tự động update types ở mọi nơi  
✅ **Giảm bugs**: Compile-time error thay vì runtime error
