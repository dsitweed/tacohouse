# Enhanced Database Design Document
## Tacohouse - Rental Room Management System

### Complete Table Structure with Tenant Document Management

#### TenantProfile Table - Bao gồm ảnh CCCD và chân dung
```sql
CREATE TABLE tenant_profiles (
    id VARCHAR(30) PRIMARY KEY DEFAULT gen_random_cuid(),
    user_id VARCHAR(30) UNIQUE NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    
    -- Document Photos (Required for tenant verification)
    id_card_front TEXT, -- URL to front ID card image (ảnh CCCD mặt trước)
    id_card_back TEXT,  -- URL to back ID card image (ảnh CCCD mặt sau)
    portrait_photo TEXT, -- URL to portrait photo (ảnh chụp chân dung)
    contract_photo TEXT, -- URL to contract image (ảnh hợp đồng - optional)
    
    -- Personal Information
    date_of_birth DATE,
    hometown VARCHAR(255), -- Quê quán
    occupation VARCHAR(255), -- Việc làm
    workplace VARCHAR(255), -- Nơi công tác hiện tại
    emergency_contact VARCHAR(255),
    emergency_phone VARCHAR(20),
    
    -- Rental Information
    move_in_date DATE,
    move_out_date DATE,
    requested_move_out_date DATE, -- For move-out requests
    is_current_tenant BOOLEAN DEFAULT false,
    
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Indexes
CREATE INDEX idx_tenant_profiles_user ON tenant_profiles(user_id);
CREATE INDEX idx_tenant_profiles_current ON tenant_profiles(is_current_tenant);
CREATE INDEX idx_tenant_profiles_move_out ON tenant_profiles(requested_move_out_date) WHERE requested_move_out_date IS NOT NULL;
```

#### Messaging System Tables
```sql
CREATE TYPE message_type AS ENUM ('TEXT', 'IMAGE', 'FILE');

-- 1-1 Messages and Group Chat Messages
CREATE TABLE messages (
    id VARCHAR(30) PRIMARY KEY DEFAULT gen_random_cuid(),
    sender_id VARCHAR(30) NOT NULL REFERENCES users(id),
    receiver_id VARCHAR(30) REFERENCES users(id), -- For 1-1 conversations
    group_chat_id VARCHAR(30) REFERENCES group_chats(id), -- For group messages
    content TEXT NOT NULL,
    message_type message_type DEFAULT 'TEXT',
    attachments TEXT[] DEFAULT '{}',
    is_read BOOLEAN DEFAULT false,
    read_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    CHECK (receiver_id IS NOT NULL OR group_chat_id IS NOT NULL)
);

-- Building Group Chats
CREATE TABLE group_chats (
    id VARCHAR(30) PRIMARY KEY DEFAULT gen_random_cuid(),
    building_id VARCHAR(30) NOT NULL REFERENCES buildings(id),
    name VARCHAR(255) NOT NULL,
    type VARCHAR(50) DEFAULT 'BUILDING', -- BUILDING or CUSTOM
    is_active BOOLEAN DEFAULT true,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Group Chat Membership
CREATE TABLE group_chat_members (
    id VARCHAR(30) PRIMARY KEY DEFAULT gen_random_cuid(),
    group_chat_id VARCHAR(30) NOT NULL REFERENCES group_chats(id),
    user_id VARCHAR(30) NOT NULL REFERENCES users(id),
    joined_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    left_at TIMESTAMP,
    is_active BOOLEAN DEFAULT true,
    
    UNIQUE(group_chat_id, user_id)
);

-- Indexes for messaging
CREATE INDEX idx_messages_sender ON messages(sender_id);
CREATE INDEX idx_messages_receiver ON messages(receiver_id);
CREATE INDEX idx_messages_group_chat ON messages(group_chat_id);
CREATE INDEX idx_messages_conversation ON messages(sender_id, receiver_id, created_at);
CREATE INDEX idx_group_chats_building ON group_chats(building_id);
CREATE INDEX idx_group_chat_members_group ON group_chat_members(group_chat_id);
CREATE INDEX idx_group_chat_members_user ON group_chat_members(user_id);
```

### Business Logic Triggers

#### Auto-update room status when move-out is requested
```sql
CREATE OR REPLACE FUNCTION handle_move_out_request()
RETURNS TRIGGER AS $$
BEGIN
    -- When tenant requests move-out, update room status
    IF NEW.requested_move_out_date IS NOT NULL AND OLD.requested_move_out_date IS NULL THEN
        UPDATE rooms 
        SET status = 'LOOKING_FOR_TENANT_BEFORE_CURRENT_LEAVES',
            available_from = NEW.requested_move_out_date
        WHERE id IN (
            SELECT room_id FROM room_tenants 
            WHERE tenant_id = NEW.id AND is_active = true
        );
    END IF;
    
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trigger_move_out_request
    AFTER UPDATE ON tenant_profiles
    FOR EACH ROW
    EXECUTE FUNCTION handle_move_out_request();
```

#### Auto-manage group chat membership
```sql
CREATE OR REPLACE FUNCTION manage_group_chat_membership()
RETURNS TRIGGER AS $$
DECLARE
    building_group_chat_id VARCHAR(30);
BEGIN
    -- Get building's group chat
    SELECT gc.id INTO building_group_chat_id
    FROM group_chats gc
    JOIN rooms r ON r.building_id = gc.building_id
    WHERE r.id = NEW.room_id AND gc.type = 'BUILDING';
    
    IF NEW.is_active = true AND OLD.is_active = false THEN
        -- Tenant moving in - add to group chat
        INSERT INTO group_chat_members (group_chat_id, user_id)
        SELECT building_group_chat_id, tp.user_id
        FROM tenant_profiles tp
        WHERE tp.id = NEW.tenant_id
        ON CONFLICT (group_chat_id, user_id) DO UPDATE SET
            is_active = true,
            left_at = NULL;
            
    ELSIF NEW.is_active = false AND OLD.is_active = true THEN
        -- Tenant moving out - remove from group chat
        UPDATE group_chat_members
        SET is_active = false, left_at = CURRENT_TIMESTAMP
        WHERE group_chat_id = building_group_chat_id
        AND user_id = (SELECT user_id FROM tenant_profiles WHERE id = NEW.tenant_id);
    END IF;
    
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trigger_group_chat_membership
    AFTER UPDATE ON room_tenants
    FOR EACH ROW
    EXECUTE FUNCTION manage_group_chat_membership();
```

### Key Features Supported:

1. **Tenant Document Management**: Complete support for ID card photos (front/back) and portrait photos
2. **Enhanced Room Status**: Supports the complex move-out workflow with advance notice
3. **Equipment Tracking**: Full equipment management for each room
4. **Request System**: Maintenance requests, move-out requests, complaints
5. **Dual Payment Confirmation**: Tenant and landlord confirmation workflow
6. **Messaging System**: 1-1 conversations and building group chats with auto-membership
7. **Notification System**: Comprehensive notification types
8. **Stripe Integration**: Full payment processing support
9. **Deposit Management**: Track deposits, refunds, and transactions

This design fully supports all the business requirements including the Vietnamese tenant verification process with ID card documentation.
