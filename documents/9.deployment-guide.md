# 🚀 Deployment Guide - Tacohouse Monorepo

## Tổng quan

Project Tacohouse là monorepo với 3 packages:
- **Backend**: NestJS API
- **Frontend**: Next.js App
- **Shared**: Types package

**Thách thức:** Deploy độc lập nhưng vẫn share types giữa BE và FE.

---

## 📦 Build Strategy

### Strategy 1: Monorepo Deploy (Recommended) ⭐

Deploy cả monorepo nhưng run từng service riêng.

**Ưu điểm:**
- ✅ Đơn giản, không cần config phức tạp
- ✅ Workspace dependencies hoạt động tự nhiên
- ✅ Dễ debug và maintain

**Nhược điểm:**
- ⚠️ Image size lớn hơn (chứa cả 3 packages)

---

### Strategy 2: Separate Deploy with Built Shared

Build shared trước, copy vào BE/FE images.

**Ưu điểm:**
- ✅ Image size nhỏ hơn
- ✅ Mỗi service độc lập hoàn toàn

**Nhược điểm:**
- ⚠️ Build pipeline phức tạp hơn
- ⚠️ Phải manage shared package version

---

## 🐳 Docker Deployment

### **Approach 1: Monorepo in Docker** (Recommended)

#### Backend Dockerfile

```dockerfile
# backend/Dockerfile.prod
FROM node:20-alpine AS builder

# Install pnpm
RUN corepack enable && corepack prepare pnpm@latest --activate

WORKDIR /app

# Copy workspace files
COPY pnpm-workspace.yaml package.json pnpm-lock.yaml ./

# Copy all packages
COPY shared/ ./shared/
COPY backend/ ./backend/

# Install all dependencies (workspace mode)
RUN pnpm install --frozen-lockfile

# Generate Prisma client (vào shared/node_modules/.prisma/client)
WORKDIR /app/backend
RUN pnpm prisma generate

# Build shared package
WORKDIR /app/shared
RUN pnpm build

# Build backend
WORKDIR /app/backend
RUN pnpm build

# Production stage
FROM node:20-alpine AS runner

RUN corepack enable && corepack prepare pnpm@latest --activate

WORKDIR /app

# Copy workspace config
COPY --from=builder /app/pnpm-workspace.yaml /app/package.json /app/pnpm-lock.yaml ./

# Copy shared package (built)
COPY --from=builder /app/shared/package.json ./shared/
COPY --from=builder /app/shared/dist ./shared/dist/
COPY --from=builder /app/shared/node_modules ./shared/node_modules/

# Copy backend
COPY --from=builder /app/backend/package.json ./backend/
COPY --from=builder /app/backend/dist ./backend/dist/
COPY --from=builder /app/backend/node_modules ./backend/node_modules/
COPY --from=builder /app/backend/prisma ./backend/prisma/

# Install production dependencies only
RUN pnpm install --prod --frozen-lockfile

WORKDIR /app/backend

EXPOSE 3000

CMD ["node", "dist/main.js"]
```

#### Frontend Dockerfile

```dockerfile
# frontend/Dockerfile.prod
FROM node:20-alpine AS builder

RUN corepack enable && corepack prepare pnpm@latest --activate

WORKDIR /app

# Copy workspace files
COPY pnpm-workspace.yaml package.json pnpm-lock.yaml ./

# Copy packages
COPY shared/ ./shared/
COPY frontend/ ./frontend/

# Install dependencies
RUN pnpm install --frozen-lockfile

# Build shared package
WORKDIR /app/shared
RUN pnpm build

# Build frontend
WORKDIR /app/frontend
RUN pnpm build

# Production stage
FROM node:20-alpine AS runner

RUN corepack enable && corepack prepare pnpm@latest --activate

WORKDIR /app

# Copy workspace config
COPY --from=builder /app/pnpm-workspace.yaml /app/package.json /app/pnpm-lock.yaml ./

# Copy shared
COPY --from=builder /app/shared/package.json ./shared/
COPY --from=builder /app/shared/dist ./shared/dist/
COPY --from=builder /app/shared/node_modules ./shared/node_modules/

# Copy frontend
COPY --from=builder /app/frontend/package.json ./frontend/
COPY --from=builder /app/frontend/.next ./frontend/.next/
COPY --from=builder /app/frontend/public ./frontend/public/
COPY --from=builder /app/frontend/node_modules ./frontend/node_modules/

# Install production dependencies
RUN pnpm install --prod --frozen-lockfile

WORKDIR /app/frontend

EXPOSE 3000

CMD ["pnpm", "start"]
```

#### docker-compose.prod.yml

```yaml
version: '3.8'

services:
  backend:
    build:
      context: .
      dockerfile: backend/Dockerfile.prod
    ports:
      - "3001:3000"
    environment:
      - NODE_ENV=production
      - DATABASE_URL=${DATABASE_URL}
      - JWT_SECRET=${JWT_SECRET}
    depends_on:
      - postgres
      - redis
    restart: unless-stopped

  frontend:
    build:
      context: .
      dockerfile: frontend/Dockerfile.prod
    ports:
      - "3000:3000"
    environment:
      - NODE_ENV=production
      - NEXT_PUBLIC_API_URL=${NEXT_PUBLIC_API_URL}
    depends_on:
      - backend
    restart: unless-stopped

  postgres:
    image: postgres:15-alpine
    environment:
      - POSTGRES_DB=${POSTGRES_DB}
      - POSTGRES_USER=${POSTGRES_USER}
      - POSTGRES_PASSWORD=${POSTGRES_PASSWORD}
    volumes:
      - postgres_data:/var/lib/postgresql/data
    restart: unless-stopped

  redis:
    image: redis:7-alpine
    volumes:
      - redis_data:/data
    restart: unless-stopped

volumes:
  postgres_data:
  redis_data:
```

### **Approach 2: Separate Docker Images**

Build shared một lần, tạo artifact, copy vào BE/FE.

#### Build Shared First

```dockerfile
# shared/Dockerfile
FROM node:20-alpine AS builder

RUN corepack enable && corepack prepare pnpm@latest --activate

WORKDIR /app

COPY package.json pnpm-lock.yaml ./
RUN pnpm install --frozen-lockfile

COPY . .
RUN pnpm build

# Export stage - tạo tarball
FROM alpine:latest
WORKDIR /output
COPY --from=builder /app/dist ./dist/
COPY --from=builder /app/package.json ./
```

#### Backend (sử dụng pre-built shared)

```dockerfile
# backend/Dockerfile.separate
FROM node:20-alpine AS builder

WORKDIR /app

# Copy shared package (pre-built)
COPY ./shared-dist ./shared/

# Install backend
COPY backend/package.json backend/pnpm-lock.yaml ./
RUN pnpm install --frozen-lockfile

COPY backend/ .

# Generate Prisma
RUN pnpm prisma generate

# Build
RUN pnpm build

# Production...
```

## ☁️ Cloud Deployment

### **Option 1: Vercel (Frontend) + Railway/Render (Backend)**

#### Frontend (Vercel)

1. **Build Settings:**
   ```bash
   # Root Directory: frontend
   # Build Command:
   cd .. && pnpm install && pnpm shared:build && cd frontend && pnpm build
   
   # Output Directory: .next
   ```

2. **Environment Variables:**
   ```env
   NEXT_PUBLIC_API_URL=https://api.tacohouse.com
   ```

3. **vercel.json:**
   ```json
   {
     "buildCommand": "cd .. && pnpm install && cd shared && pnpm build && cd ../frontend && pnpm build",
     "installCommand": "cd .. && pnpm install"
   }
   ```

#### Backend (Railway/Render)

1. **Build Command:**
   ```bash
   pnpm install && cd shared && pnpm build && cd ../backend && pnpm prisma generate && pnpm build
   ```

2. **Start Command:**
   ```bash
   cd backend && pnpm prisma migrate deploy && node dist/main.js
   ```

3. **Environment Variables:**
   ```env
   DATABASE_URL=postgresql://...
   JWT_SECRET=...
   NODE_ENV=production
   ```

### **Option 2: AWS (ECS/EC2)**

#### Using Docker Compose

```bash
# 1. Build images
docker-compose -f docker-compose.prod.yml build

# 2. Push to ECR
aws ecr get-login-password --region us-east-1 | docker login --username AWS --password-stdin <account>.dkr.ecr.us-east-1.amazonaws.com

docker tag tacohouse-backend:latest <account>.dkr.ecr.us-east-1.amazonaws.com/tacohouse-backend:latest
docker push <account>.dkr.ecr.us-east-1.amazonaws.com/tacohouse-backend:latest

docker tag tacohouse-frontend:latest <account>.dkr.ecr.us-east-1.amazonaws.com/tacohouse-frontend:latest
docker push <account>.dkr.ecr.us-east-1.amazonaws.com/tacohouse-frontend:latest

# 3. Deploy to ECS
aws ecs update-service --cluster tacohouse --service backend --force-new-deployment
aws ecs update-service --cluster tacohouse --service frontend --force-new-deployment
```

## 🔄 CI/CD Pipeline

### GitHub Actions

```yaml
# .github/workflows/deploy.yml
name: Deploy

on:
  push:
    branches: [main]

jobs:
  # Job 1: Build Shared
  build-shared:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - uses: pnpm/action-setup@v2
        with:
          version: 8
      
      - uses: actions/setup-node@v3
        with:
          node-version: '20'
          cache: 'pnpm'
      
      - name: Install dependencies
        run: pnpm install --frozen-lockfile
      
      - name: Build shared package
        run: cd shared && pnpm build
      
      - name: Upload shared artifact
        uses: actions/upload-artifact@v3
        with:
          name: shared-dist
          path: shared/dist/

  # Job 2: Build & Deploy Backend
  deploy-backend:
    needs: build-shared
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Download shared artifact
        uses: actions/download-artifact@v3
        with:
          name: shared-dist
          path: shared/dist/
      
      - name: Build Docker image
        run: docker build -f backend/Dockerfile.prod -t backend:${{ github.sha }} .
      
      - name: Push to registry
        run: |
          echo ${{ secrets.DOCKER_PASSWORD }} | docker login -u ${{ secrets.DOCKER_USERNAME }} --password-stdin
          docker tag backend:${{ github.sha }} username/tacohouse-backend:latest
          docker push username/tacohouse-backend:latest
      
      - name: Deploy to server
        uses: appleboy/ssh-action@master
        with:
          host: ${{ secrets.SERVER_HOST }}
          username: ${{ secrets.SERVER_USER }}
          key: ${{ secrets.SSH_KEY }}
          script: |
            cd /app/tacohouse
            docker pull username/tacohouse-backend:latest
            docker-compose up -d backend

  # Job 3: Build & Deploy Frontend
  deploy-frontend:
    needs: build-shared
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Download shared artifact
        uses: actions/download-artifact@v3
        with:
          name: shared-dist
          path: shared/dist/
      
      # Deploy to Vercel
      - name: Deploy to Vercel
        uses: amondnet/vercel-action@v20
        with:
          vercel-token: ${{ secrets.VERCEL_TOKEN }}
          vercel-org-id: ${{ secrets.ORG_ID }}
          vercel-project-id: ${{ secrets.PROJECT_ID }}
          working-directory: ./frontend
```

## 📝 Deployment Checklist

### Pre-deployment

- [ ] Build shared package: `cd shared && pnpm build`
- [ ] Run backend build: `cd backend && pnpm build`
- [ ] Run frontend build: `cd frontend && pnpm build`
- [ ] Test locally với production build
- [ ] Run migrations: `pnpm prisma migrate deploy`
- [ ] Set environment variables
- [ ] Test database connection

### Backend Deployment

- [ ] Set `DATABASE_URL`
- [ ] Set `JWT_SECRET`
- [ ] Set `NODE_ENV=production`
- [ ] Run `prisma migrate deploy`
- [ ] Check health endpoint
- [ ] Verify API responses

### Frontend Deployment

- [ ] Set `NEXT_PUBLIC_API_URL`
- [ ] Build với correct API URL
- [ ] Test API connectivity
- [ ] Check SSR/CSR rendering
- [ ] Verify types are working

### Post-deployment

- [ ] Monitor logs
- [ ] Check error rates
- [ ] Test critical user flows
- [ ] Database backup
- [ ] Setup monitoring (Sentry, etc.)

- Full control
- Scalable

- Full control

## 🐛 Troubleshooting

### Issue: "Cannot find module '@tacohouse/shared'"

**Solution:**
```bash
# Make sure shared is built
cd shared && pnpm build

# Reinstall workspace dependencies
pnpm install
```

### Issue: Prisma client not generated

**Solution:**
```bash
cd backend
pnpm prisma generate
```

### Issue: Frontend can't connect to Backend

**Solution:**
- Check `NEXT_PUBLIC_API_URL` environment variable
- Verify CORS settings in backend
- Check network/firewall rules
